# Contributing

Thank you for helping improve **Awesome IAM Labs**.

The goal is to keep this repository practical, technically sound, and useful to learners and IAM practitioners.

## Good contributions

- Hands-on labs with reproducible steps
- Identity architecture diagrams and flow explanations
- Entra, Okta, SailPoint and workload identity examples
- IAM operations and incident investigation scenarios
- Corrections, clarifications and updated vendor references
- Interview questions based on realistic engineering situations

## Before opening a pull request

1. Search existing guides to avoid duplicating material.
2. For a substantial change, open an issue first to discuss the proposed scope.
3. Use Markdown headings and descriptive file names.
4. Distinguish verified behaviour from assumptions or personal observations.
5. Link official vendor documentation for product-specific claims where appropriate.

## Lab submission checklist

A useful lab should include:

- **Objective:** What should the learner understand or accomplish?
- **Prerequisites:** Tenant, license, role, tools and setup required.
- **Scenario:** The real-world identity or access problem.
- **Steps:** Clear, ordered instructions.
- **Expected result:** What should happen?
- **Validation:** How to prove that it worked (or failed as expected).
- **Troubleshooting:** Common failure points and diagnostic evidence.
- **Cleanup:** How to remove test objects and avoid unexpected costs.

## Security and privacy

- Never commit passwords, access tokens, client secrets, private keys or credentials.
- Use fictional names and sanitized identifiers in examples.
- Remove personal, customer and tenant-sensitive data from screenshots and logs.
- Do not include destructive instructions without clear warnings and safe test guidance.
- Test scripts in a non-production environment before submitting them.

## Writing style

Prefer concise explanations, meaningful headings, tables for comparisons, and code blocks for commands. Explain acronyms on first use. Keep the learner's objective visible throughout the lab.

Thank you for sharing your knowledge with the IAM community.
