## Learn by doing

A productive lab loop:

1. **Frame the problem** — identify the identity, resource, trust boundary and expected access.
2. **Build or inspect** — use an isolated tenant or lab environment.
3. **Test both paths** — validate expected behaviour and a negative/failure case.
4. **Collect evidence** — inspect logs, claims, assignments, policy decisions or command output.
5. **Explain the result** — document root cause, remediation and cleanup.

!!! warning "Use a safe environment"
    Some exercises require licensed services, cloud resources or vendor-specific tooling. Check prerequisites and potential costs before starting. Do not run destructive experiments against production identities or access.
